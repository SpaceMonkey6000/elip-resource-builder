Prove it · the differentiator

Please, not the Titanic dataset again.

Hiring managers are drowning in Titanic/Iris tutorial projects — they prove you can follow a guide, nothing more. Source raw, messy data and simulate a real business problem. The cleaning is the skill.

Source messy, real data

data.govUS CensusWHO / CDCFiveThirtyEightKaggleGoogle Dataset Search

Seek datasets that need real preprocessing — missing values, messy dates, duplicates, disjoint tables to join.

Every project needs

Business context (why it matters) → pipeline method (how you got & cleaned it) → techniques → visual deliverable → executive summary of the insight. Host code on GitHub with a real README; deep-dives on Notion, Framer or Webflow.

1 · E-commerce segmentation

SQL extract → RFM analysis in Pandas → interactive Tableau/Power BI dashboard + strategy memo.

2 · Public-health risk

CDC/WHO data → correlation & hypothesis testing in a Jupyter notebook → resource-allocation brief.

3 · Financial variance tracker

Relational DB → automated 3-statement model / Power BI updating via Power Query.

4 · A/B testing framework

Control vs. treatment → sample size, power analysis, p-values → plain-English recommendation.

✅ Templates that parse

  • Jake's Resume (LaTeX/Overleaf) — flawless encoding for data/quant roles.
  • Harvard standard (.docx) — gold standard for business/finance.
  • FlowCV / SartorCV — genuinely free, ATS-safe, no export paywall.

✕ ATS myths & traps

  • It's not scoring you /100 — it's parsing you. Bad format = invisible.
  • No skill-bars, icons, text boxes or layout tables.
  • No keyword-stuffing in white text — it's detected and penalized.
